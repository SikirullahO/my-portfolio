01 / About

A little about me

I'm a Computer Science student at Ahmadu Bello University, Nigeria. I started learning software development in 2023, beginning with full-stack web development: building pages, wiring up interactivity, and slowly figuring out how the frontend and backend fit together.

That foundation taught me to think about the whole application: how an interface feels to use, how an API is shaped, and how data moves between them. I've worked with JavaScript, React and Node.js, and more recently with Python and FastAPI.

Lately I've been drawn to AI engineering, especially the practical side: how LLM APIs fit into real applications, how retrieval keeps answers grounded in source material, and how agents can use tools in controlled, predictable ways.

My goal is simple: write software that is reliable and genuinely useful, and keep getting better at the engineering habits that make it so: testing, documentation, and clear design.
